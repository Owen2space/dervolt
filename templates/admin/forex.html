About Forex Rates

The system fetches USD/KES exchange rates from Open Exchange Rates API every 12 hours. These rates are used for calculating deposit and withdrawal amounts.

Rate Structure

  • Base rate: The current market rate from Open Exchange Rates API
  • Deposit rate: Higher rate ({{ '%.2f' | format((132.90 / 129.50) * 100) }}% of base) with 1% fee applied
  • Withdrawal rate: Lower rate ({{ '%.2f' | format((126.20 / 129.50) * 100) }}% of base) with 1.5% fee applied
  • The rates displayed throughout the system include fees for transparency

Fee Structure

  • Deposits: 1% fee of the USD amount
  • Withdrawals: 1.5% fee of the USD amount
  • Fees are applied to all transactions and are included in all calculations
  • When a user deposits USD, the fee is deducted from the USD amount before conversion
  • When a user withdraws USD, the fee is deducted from the USD amount before conversion

You can manually update the exchange rate by entering a value in the form above. If no value is entered, the system will fetch the latest rate from the API.
